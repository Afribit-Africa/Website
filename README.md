# Afribit Africa

**Empowering Communities Through Bitcoin Adoption in Africa**

---

## About

Afribit Africa is a non-profit organization dedicated to fostering Bitcoin adoption and financial inclusion across African communities. We focus on Kenya's Kibera settlement, bridging traditional communities with the global Bitcoin economy through education, merchant onboarding, and community development.

## Mission

Empowering African communities through Bitcoin technology, creating economic opportunities, and building sustainable digital finance infrastructure.

## Platform Overview

### Core Features
- Bitcoin merchant directory with interactive maps
- Lightning Network payment integration
- Two-step merchant verification system
- Community program management
- Donor tracking and transparency
- Admin dashboard for operations

### Technology Stack
- Next.js 14 with TypeScript
- MySQL database
- Google OAuth authentication
- BTCPay Server integration
- OpenStreetMap & BTCMap integration
- Resend email service

## Programs

- **BodaBoda Bitcoin Initiative** - Onboarding motorcycle taxi drivers
- **Waste Management Program** - Bitcoin-incentivized recycling
- **Merchant Support** - Business verification and payment solutions
- **Education** - Community workshops and training
- Marketing and visibility for participating merchants

### 💰 Donation Platform
- Transparent donation tracking via Bitcoin
- Lightning Network support for instant donations
- On-chain Bitcoin donations
- Real-time donation statistics and impact metrics
- Donor recognition program

### 🗺️ BTCMap Integration
- Direct integration with global Bitcoin merchant network
- OpenStreetMap data synchronization
