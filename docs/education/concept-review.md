# Concept review, 2026-10-01

Inspected `bitcoin-studio-concept.webp` with the local image viewer before
application implementation. Provider: OpenRouter, model
`google/gemini-3.1-flash-image`. Reported generation cost: USD 0.101097.

Useful composition: architectural Bitcoin sculpture, titanium rings, translucent
linked ledger blocks, mint connectors, vertical episode sidebar, waveform player.
The sculpture is inspectable and physically grounded rather than atmospheric.

Corrections for implementation:

- Preserve the requested full charcoal/near-black environment. The model chose
  a large pale left background despite the dark palette request.
- Use compact 36-42 px display type instead of the oversized generated heading.
- Use modest square-edged player surfaces and an unframed transcript overlay.
- Ignore generated row timings and sample transcript. These are explicitly
  concept placeholders, not actual audio data.
- Use real lucide icons and semantic controls in application code.

The scenic asset prompt in `network-prompt.json` removes all UI/text and explicitly
corrects the backdrop. The concept remains documentation, not a shipped screenshot.
